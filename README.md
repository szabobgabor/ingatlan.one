# Ingatlan.One

A Domain-Driven Design (DDD) inspired real estate showcase platform built with a custom micro-framework. This is a pet project by a real estate agent and programmer, focusing on showcasing properties while maintaining clean architecture principles and minimal technical debt.

## 🏗️ Project Overview

**Ingatlan.One** is a lightweight real estate portfolio application designed to display properties in a professional and intuitive manner. The project prioritizes architectural clarity, maintainability, and extensibility while avoiding over-engineering.

### Key Characteristics

- **Domain-Driven Design**: The architecture follows DDD principles with clear domain boundaries
- **Custom Micro-Framework**: Built on a minimal, purpose-built framework focusing on essential requirements
- **Clean Architecture**: Organized into Application, Domain, Framework, Infrastructure, Presentation, and Shared layers
- **Zero External Framework Overhead**: No monolithic frameworks—only what's needed
- **Minimal Technical Debt**: Intentional design choices to keep the codebase maintainable and scalable
